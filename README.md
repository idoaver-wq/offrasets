# Offer Nissim Set Lists

Archive of Offer Nissim party set lists - https://offrasets.com

## Layout

- `src/` - source of truth: the data (CSV), `template.html` and `build.py`
- `images/` - party invitation images, named by event id (e.g. `sukkot_2026.jpg`)
- `index.html` - the built site. Do not edit by hand, it is generated by `src/build.py`
- `CNAME`, `.nojekyll` - GitHub Pages settings for offrasets.com

## Data files (src/)

- `events.csv` - one row per party (EVT_01...), set start/end, venue
- `tracks.csv` - every track played, by event_id + sequence_number
- `archive.csv` - same tracks, flat, with readable event ids (e.g. `pride_tel_aviv_2026`); also defines the EVT_xx -> readable id order
- `canonical_songs.csv` - one row per song (SONG_xxxx)
- `track_aliases.csv`, `archive_review.csv` - normalization records
- `live_links.csv` - live recordings per party (shown only when `approved` = yes)
- `track_links.csv` - listening links per song (display paused: `SHOW_TRACK_LINKS = False` in build.py)

A correction to a track is made in both `tracks.csv` and `archive.csv`, with a dated note.
Image credits (parties not recorded by the archive owner) are in `CREDIT` in build.py.

## Updating

```
python3 src/build.py      # rewrites index.html; the "updated" date is set automatically
git add -A && git commit -m "..." && git push
```

GitHub Pages republishes within a minute or two.
